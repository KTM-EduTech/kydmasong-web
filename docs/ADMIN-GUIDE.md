# Admin guide

Sign in at **/admin**. Everything you change is saved to the database and appears on the public site
within seconds. You never need to edit code for content.

## Dashboard
Counts of pages, projects, posts, media and new enquiries; quick actions; **Needs your review** (items
flagged during migration or by you) and **Recent updates**.

## Pages
- **New page**: give it a title (and optionally a slug). It starts as a draft with a page header.
- **Sections**: each page is a stack of sections. *Add section* to choose a type; click a section to
  edit it; drag the handle to reorder; the eye icon hides/shows; you can duplicate or delete.
- **Save** keeps the current status. **Save & publish** makes it public. **Unpublish** returns it to draft.
- **Preview** opens the page as visitors will see it, including drafts (save first).
- **Page settings & SEO**: title, URL slug, sitemap, search title/description, social image, noindex.
  If you change a slug, add a redirect from the old URL under *Redirects*.
- The homepage is the page with the slug `home`; it cannot be deleted.

### Section types
Hero · Page header · Introduction with portrait · Rich text · Toolkit strip · Timeline · Featured
projects · All projects · Services · Skills · Work experience · Cards · Pull quote · Impact counters ·
Testimonials · Call to action · Contact form · Location and availability · Embed (Book Creator, YouTube,
Google Maps) · Link groups · Image.

*Impact counters* and *Testimonials* are hidden by default. Testimonials only show quotes where
"Permission to publish obtained" is ticked.

## Rich text editor
Headings, bold/italic/underline, lists, quotes, callout blocks, dividers, alignment, links (pick a page
or enter a URL), images from the media library (with alt text and left/centre/right/full alignment),
YouTube videos and tables.

## Projects, Work experience, Skills, Services
Add, edit, publish/unpublish, delete and drag to reorder. Projects have categories, tags, a cover,
a gallery, external links and a *Featured on homepage* switch; use the *Featured order* tab to order the
homepage grid.

## Blog
Write posts with the same editor, categories, tags, featured image, SEO and an optional future publish
date (scheduling). The blog is hidden until you switch on **Settings → Blog enabled** and add a Blog link
under *Navigation*.

## Media library
Upload images and PDFs (10 MB max), organise them in folders, edit alt text and captions, **Replace** a
file everywhere it is used, see where an item is used, and delete. Items marked *External link* still
live on the old host; use **Copy into library** to store your own copy.

## Navigation
Header and four footer menus. Add items that link to a page or a URL, rename, drag to reorder, indent
to create dropdowns, disable, open in a new tab, or show as the gold header button. Links to
unpublished pages hide themselves.

## Enquiries
Messages from the contact form (stored securely; only admins can read them). Opening one marks it read;
reply by email, archive or delete.

## Settings
Logo, favicon, brand colours, theme default, contact email, locations and map, availability, enquiry
types, Privacy Policy link, footer text, social links, default SEO, and the blog switch.

## Account & security
Change your password and turn on two-factor sign-in.
